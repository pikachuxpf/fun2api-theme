# fun2api-theme

Frontend-only snapshot of the official [Sub2API](https://github.com/Wei-Shaw/sub2api) frontend
(`frontend/` directory, upstream commit `ab99d56e9626e6cd731592dae8553c9758a0efa2`).

The custom replaceable theme layer has been removed; this repository now tracks the official
frontend sources so the server build matches the upstream project exactly.

This repository intentionally excludes backend code, production configuration, databases, logs,
dependencies, build output, and credentials.
